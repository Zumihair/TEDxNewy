The drifting node-and-edge constellation behind dark flagship sections — the site's one ambient background motif.

```jsx
<section style={{ position: "relative", background: "var(--red-deep)" }}>
  <NodeNetwork variant="light" opacity={0.3} />
  …
</section>
```

Requires a `position: relative` parent. Never on cream body sections, never more than one per page, and always with the grain overlay or a radial glow rather than on flat colour alone.
