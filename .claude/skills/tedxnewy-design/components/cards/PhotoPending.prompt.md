Deliberate placeholder for an event whose photos aren't published yet — brand-red gradient, image glyph, "Photos coming soon".

```jsx
<div style={{ position: "relative", aspectRatio: "4/3" }}>
  <PhotoPending title="Youth Futures Lab" />
</div>
```

Always red, whatever the event kind, so awaiting-photos reads as one state. Use it anywhere a card photo panel could be empty instead of leaving a flat gradient.
