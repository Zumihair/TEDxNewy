The default hero for every page except the dark-hero set (/, /signal, past flagship events): cream, red kicker, one big sentence-case title, an intro paragraph.

```jsx
<PageHero kicker="About TEDxNewy" title="Ideas worth spreading, from Newcastle"
  intro="We are 100% volunteer-run, not-for-profit, and independently licensed." />
```

Titles are sentence case and can run to two lines; don't add decoration, imagery or a background to this hero.
