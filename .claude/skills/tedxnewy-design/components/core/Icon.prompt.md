One-stop wrapper around the Lucide glyphs the TEDxNewy site uses; reach for this instead of pasting inline SVG.

```jsx
<Icon name="arrow-right" size={16} strokeWidth={2.25} />
```

Names: arrow-right, arrow-up-right, arrow-left, chevron-down/left/right, menu, x, play, mail, map-pin, calendar, image. Colour follows `currentColor` unless you pass `color`. Anything not in the list should be added to `Icon.jsx` from lucide.dev rather than drawn by hand.
