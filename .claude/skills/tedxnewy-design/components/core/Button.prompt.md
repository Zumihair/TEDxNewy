The one button shape on the site: a pill, 14px/500 label, colour shift plus a 1px lift on hover. Use it for every action.

```jsx
<Button variant="red" href="/signal" icon="arrow-right">Get tickets</Button>
<Button variant="secondary">Read the mission</Button>
```

Choosing a variant: on cream, `primary` (ink) or `red` for the one main action, `secondary` for the alternative. On a dark hero, `white`/`cream` for the main action and `outline-light`/`ghost-light` beside it. Never introduce a new radius, padding or a squared button.
