Lucide icon by name, matching the icon set the TEDxNewy admin imports from `lucide-react`.

```jsx
<Icon name="Pencil" size={14} strokeWidth={2.25} />
```

Requires the lucide UMD script on the page (`https://unpkg.com/lucide@latest`). Names are lucide's PascalCase names. Sizes in use: 14 (row action buttons), 15 (sidebar), 16 (fields, modals), 18 (dashboard tiles).
